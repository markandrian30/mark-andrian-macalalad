Kibo

Kibo is a voice assistant that runs on a Raspberry Pi 5 and uses a Qwen language model on the university's DGX servers. It talks in real time, so you can speak to it and hear an answer back without waiting. Here is what it can do.

  • Real-time conversation

    Kibo talks in real time, so a conversation feels natural rather than a slow back-and-forth. You can ask it things and hear an answer right away.

  • Web pages and apps

    Kibo builds web pages and apps on request. It can put together the code and structure for a new page or application.

  • Music on Spotify

    Kibo plays music on Spotify. You can ask it to start a song or a playlist and it will play it for you.

  • Flights and movie showtimes

    Kibo checks flights and movie showtimes. Ask it about a flight or a film and it will look up the details.

  • Chemistry questions

    Kibo answers chemistry questions using PubChem. It pulls information from that database to help with chemistry.

  • Machine-learning jobs

    Kibo runs machine-learning jobs on the DGX. It can kick off ML workloads on the university's DGX servers.
